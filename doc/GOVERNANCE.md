# Governance

## Mission

Build the best open-source toolkit for Stellar mobile development.

---

## Maintainers

Maintainers are responsible for:

* Reviewing pull requests
* Managing releases
* Defining roadmap priorities
* Security oversight

---

## Contributors

Contributors may:

* Submit pull requests
* Open issues
* Improve documentation
* Participate in discussions

---

## Decision Making

### Small Changes

Maintainer approval required.

Examples:

* Documentation
* Bug fixes
* Refactoring

---

### Major Changes

Require:

* Design discussion
* Community feedback
* Maintainer consensus

Examples:

* Breaking API changes
* New architecture
* Wallet integrations

---

## Release Process

### Patch

Bug fixes.

Example:

```text
1.0.1
```

### Minor

Backward-compatible features.

Example:

```text
1.1.0
```

### Major

Breaking changes.

Example:

```text
2.0.0
```

Semantic Versioning is followed.

---

## Code of Conduct

We strive to maintain a welcoming environment.

Expected behavior:

* Respectful communication
* Constructive feedback
* Inclusive participation

Unacceptable behavior:

* Harassment
* Discrimination
* Personal attacks

---

## Community Values

* Openness
* Transparency
* Collaboration
* Technical excellence
* Long-term sustainability
