# Stellar Mobile Wallet Kit Documentation

Official documentation repository for the Stellar Mobile Wallet Kit ecosystem.

This repository contains all developer guides, architecture documentation, security specifications, tutorials, contributor resources, and ecosystem documentation for:

* stellar-react-native-wallet-kit
* stellar-rn-wallet-kit-example
* Future ecosystem packages

---

# Purpose

The goal of this repository is to provide a single source of truth for developers building mobile applications on Stellar and Soroban.

Rather than scattering documentation across multiple repositories, this project centralizes:

* Getting Started Guides
* SDK Documentation
* API References
* Architecture Documentation
* Security Documentation
* Contributor Guides
* Tutorials
* Migration Guides
* Ecosystem Standards

---

# Who This Is For

## Application Developers

Learn how to:

* Connect wallets
* Sign transactions
* Build Soroban dApps
* Handle account state
* Integrate WalletConnect

## Contributors

Learn:

* Repository architecture
* Development workflow
* Contribution process
* Testing requirements

## Ecosystem Projects

Use this documentation as a reference for integrating with the Stellar Mobile Wallet Kit ecosystem.

# Documentation Principles

## Developer First

Documentation should solve real developer problems.

## Practical Examples

Every major feature should include working examples.

## Accuracy

Documentation must match the current SDK release.

## Accessibility

Documentation should be approachable for developers new to Stellar.
